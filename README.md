# Chatbot Taborra Alarmas

Este repositorio contiene el backend desarrollado con **FastAPI** y un front en **React** para el panel de administración.

El dashboard utiliza la misma API que usa el agente, por lo que no es necesario crear un servicio aparte. Todo el backend está bajo la carpeta `server`.

## Estructura

- **server**: código del backend.
- **client**: aplicación React con Vite.

## Uso rápido

### Backend

```bash
cd server
pip install -r requirements.txt
./run.sh
```

### Frontend

```bash
cd client
npm install
npm run dev
```
